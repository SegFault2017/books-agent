# books-agent

A Claude Code plugin that bundles the book knowledge-base skills generated by `/book-to-skill`
(frameworks, chapter summaries, glossary, patterns, cheatsheet per book).

## Add a book

1. Run `/book-to-skill <file>` — it writes the skill to `~/.agents/skills/<name>`.
2. Run `./sync.sh` to copy every book skill into `skills/`.
3. Bump `version` in `.claude-plugin/plugin.json`, then commit and push.
4. On each machine: `/plugin marketplace update books-agent`.

## Install

Private repo — git must be able to clone it (`gh auth login` or SSH key).

```
/plugin marketplace add SegFault2017/books-agent
/plugin install books-agent@books-agent
```

For background auto-updates of a private marketplace, set `GITHUB_TOKEN` in your shell.
